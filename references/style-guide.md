# 侨批写作风格指南 & 完整模板库

> 本文件是 baoyu-qiaopi 技能的详细写作参考，包含完整的结构模板、金句库、范例信件。

---

## 一、结构详解

### 完整七段式模板

```
【第一段：称呼问安】
[关系称谓]大人：
　展信安好。

【第二段：寄银交代】（侨批灵魂）
　随信寄入[金额]元/银[XX]元，祈为查收。家中若有所需，尚望来信告知。
[或无银款时]　薄资些许，聊补家用，祈为笑纳。

【第三段：自述近况】
　我在[地点]诸事尚可，[季节]已至，[简述一件好事，不提任何烦恼]。身体安稳，请勿挂念。

【第四段：借景思乡】（最核心氛围段落）
　今日[时节风物]，想起从前在家时[一件家常小事/风物/场景]。阿嬷[相关的家常记忆，隐忍克制地表达思念]。

【第五段：叮嘱保重】
　近日[天气/时节]，望[收信人]多加保重，勿要操劳，闲时多歇息。家中大小事务，量力而行便是。

【第六段：收尾寄语】
　江水滔滔，思念不减。盼[收信人]一切顺遂，岁岁平安。
[或用金句]　江海万里，心有所寄，便不觉远。

【第七段：落款】
　[身份][姓名]字
　[公历/农历日期]
```

## 二、金句库（按场景分类）

### 寄银后报平安
- 诸事尚可，身体安稳，勿劳挂念。
- 此间一切顺遂，堪可告慰。
- 日前店务渐有头绪，堪可告慰家人。

### 思念家乡（时节风物）
- 春来江水绿，乡思满蓬舟。
- 秋深了，枫叶红时，想念家里那棵老榕树。
- 近日多雨，听雨声想起幼时在老屋檐下躲雨的光景。
- 夜里风凉，枕上不知多少回梦见家中炊烟。
- 故乡月圆，异乡月亦圆，只是无人共赏。

### 叮嘱保重
- 家中大小平安，便是人间圆满。
- 望各人保重身体，勿要挂念我。
- 天凉了，添衣吃饭，万事小心。
- 闲时多歇息，莫要太过操劳。

### 收尾寄语
- 江海万里，心有所寄，便不觉远。
- 身在异乡，日夜心念家中人事。
- 岁月匆匆，唯愿亲人安稳，岁岁如常。
- 盼来信告知家中近况，以释远念。
- 此信寄出，不日或有音书，盼安。

## 四、范例信件

### 范例一：祖孙之间（阿嬷收）
```
阿嬷大人：
　展信安好。

　随信寄入贰佰元，祈为查收。阿嬷若有什么要买，尚望来信告知。

　我在南洋诸事尚可，雨季已至，海上近来风平浪静，生意尚可维持。身体安稳，请阿嬷勿要挂念。

　昨夜梦见老屋门前那口古井，井边阿嬷洗衣的身影，醒来良久难忘。故乡夏夜蚊虫多，阿嬷记得燃艾草驱蚊，早些歇息。

　近日天气炎热，望阿嬷多加保重，勿要太过操劳。饮食定量，起居有时，万事小心。

　江水滔滔，思念不减。盼阿嬷一切顺遂，岁岁平安。

　孙XX字
　农历XX年XX月XX日
```

### 范例二：夫妻之间
```
娘子：
　展信安佳。

　随信寄上银佰元，家中若有所需，来信即寄，切勿省用。

　我在此一切顺遂，店铺生意日渐起色，堪可告慰。夜来无事，常在阳台望月，想起你在窗前做活的身影。

　记得那年你送我到渡口，如今渡口犹在，你我却隔了万里海天。唯愿你在家照顾好自己，勿要太省。

　天气渐凉，望妻多添衣裳，照顾好老小。有你在家，我在外便安心了。

　此信寄出，不日当有音书。盼一切安好。

　夫XX字
　XX年XX月XX日
```

### 范例三：无汇款，仅传思念
```
母亲大人：
　展信安好。

　男近来诸事尚可，店中忙碌，身体无恙，请母亲放心。

　昨夜风凉，想起幼时母亲在灯下缝补的背影，针线穿过布面的声音，至今犹在耳畔。天冷了，母亲的老寒腿可曾发作？切记多加衣物。

　我在外一切尚好，母亲不必挂念。只盼母亲在家平安康健，便是男最大的心愿。

　诸事尚可，身体安稳，勿劳挂念。

　儿XX字
　农历XX年XX月
```

## 五、禁忌词汇清单（绝对禁止出现）

### 现代词/网络语
绝对禁止：哈哈哈、亲、么么哒、爱你、想你了、网红、电商、微商、直播、带货、疫情（可写"近年多事"）、封控、核酸、疫苗等一切2020年后特有词汇。

### 空洞大话
绝对禁止：伟大、奋斗、梦想、幸福、未来可期、不忘初心等宣教类词汇。

### 过于直白的情感表达
绝对禁止：我想你、我爱你、我好想你、想家想到哭等直白表述。

### 现代事物
绝对禁止：手机、电脑、网络、微信、QQ、快递、飞机（可写"航程"）、高铁等现代交通工具直接名称。

## 六、写作检查清单

生成完毕后，逐项核对：

- [ ] 有无报忧内容（有任何烦恼、辛苦、抱怨？ → 必须删除）
- [ ] 思念是否直白（直接写"我想你"？ → 改为景物/时节/小事）
- [ ] 结构顺序是否正确（银钱→近况→思念→叮嘱→收尾→落款）
- [ ] 有无现代词汇（逐一扫描，禁止词库）
- [ ] 句式是否过短/干净（每句不超过25字，不冗长）
- [ ] 落款格式是否正确（身份+字+日期）
